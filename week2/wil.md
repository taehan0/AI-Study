# AI스터디 2주차

'AI가 학습하는 방법'에 대해서 배웠다. 먼저 학습이란, 모델이 추론을 잘 하도록 모델의 구조를 문제에 최적화하는 과정이다. 이를 수학적으로 표현하면 모델을 f_세타(x)로 보면, x를 고정하고 세타값을 바꾸는 것이다. 학습을 진행하며 파라미터가 바뀌고, 이로 인해 오차를 줄이는 방식으로 학습을 진행한다. 네가지 단계를 거치며 예측 -> 오차 확인 -> 방향 계산 -> 가중치 조절이 그것이다.

방향 계산시에는 Gradient로 방향을 인지하고, 그 반대로 움직이면 된다. 얼마나 움직일지는 learning rate로 결정하는데, 이것은 너무 작아도 안되고 너무 커서도 안된다. 너무 작으면 불필요한 계산이 많아지고, 너무 크면 오히려 오차가 더 커질 수 있다.

Optimizer에서는 주로 Adam방식을 쓰는데, 이는 작은 웅덩이들은 관성으로 넘어가며, 가중치마다 보폭을 조절하여 일정하게 움직이는 최적화 방식이다.
